# 阶段 3 · 标准答案

1. 问句 →（可选改写）→ 嵌入/关键词检索 → 权限过滤 → 重排 → 把片段塞进 Prompt → 生成+引用。最常砸：切片切错语义、没过滤权限、召回差还硬生成。

2. 那是把 RAG 退化成普通聊天。量化上会变成「没数据的研报」。拒答是功能。

3. 必须在检索/过滤。只写 Prompt：模型仍可能看见不该看见的 chunk（已进上下文），存在泄露与遵从恶意片段的风险。

4. 太大：噪声多、引用不准。太小：破句、召回碎片。overlap 减轻边界切断。要用评测集调，不要玄学。

5. 直接越狱针对 system。间接注入藏在检索到的不可信内容里。攻击面是新闻/公告 chunk。对策：内容与指令隔离、工具白名单、对检索文本不当指令执行。

6. 固定集算 hit@k、拒答是否该拒、citation 是否指向真正支持答案的 chunk。改参数只看这张表，不看体感。
