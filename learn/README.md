# 分阶段学习包（开挂写代码 + 自己能讲出来）

第一性原理：**会，是指能教给别人。**  
AI 可以写代码；你必须能在白板上画出数据流、失败路径和为什么这样设计。讲不出来，这个阶段就没过。

总路线：[LEARNING.md](../LEARNING.md)  
量化协作：[QUANT_ARCHITECTURE.md](../QUANT_ARCHITECTURE.md)

## 每个阶段三份文件

| 文件 | 谁用 | 何时打开 |
|------|------|----------|
| `STUDY.md` | 你 + Cursor/Claude | 一开始就读 |
| `QUESTIONS.md` | 你当考生 | **写完本阶段代码、自己先答完** 再对照 |
| `ANSWERS.md` | 验收官标准答案 | **最后**打开。先看等于没练 |

把你的手写答案放到本阶段目录的 `MY_ANSWERS.md`（已 gitignore，不会提交）。

## 每阶段固定流程

```
打开 STUDY.md
  → 用里面的提示词让 Cursor 写（一次只做一步）
  → 对着「★ 必懂」把代码讲给空气听 / 录音 3 分钟
  → 跑验收接口
  → 合上电脑答 QUESTIONS.md
  → 对照 ANSWERS.md
  → 讲不清的点，回去改代码或补读指定文档，不要进下一阶段
```

## ★ 全局硬规则

1. 永远在 **本仓库** 里改，不新开 Demo 工程。
2. 提示词里已经写了「不要跳过必懂点」。AI 若把核心逻辑藏进魔法工具类，你必须让它拆开。
3. 论文只读 STUDY 里点名的那几页，不要开新课。
4. 阶段 0 没对 LongCat 跑通对话，禁止开始阶段 1。
