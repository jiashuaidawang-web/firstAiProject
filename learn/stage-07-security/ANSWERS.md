# 阶段 7 · 标准答案

1. 利益冲突与失败模式相同：模型会为了「完成用户目标」而弱化风险。独立模块用确定性规则+审计，不依赖同一套 Prompt。组织上像风控部 vs 交易部。

2. 用户越狱；RAG 公告/新闻间接注入；工具返回（网页抓取、券商错误信息）再注入。三处都要把「数据」和「指令」分开。

3. 给模型的工具比用户权限更大或缺少闸门。必须闸住：Execution。投研环可以自动，交易环默认关。

4. 以系统状态机为准，不以模型文本为准。UI 只渲染 Portfolio/Risk/Execution 模块的 JSON，不渲染模型散文里的「已成交」。

5. 工具列表按角色装配。没挂上的工具模型调用会被运行时拒绝。不是靠「请不要调用」。

6. 口试要点：无工具、有闸、有审计、有红队测试、有独立风控规则。缺一不可。
