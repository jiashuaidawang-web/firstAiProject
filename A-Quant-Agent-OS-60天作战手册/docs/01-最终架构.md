# 最终架构

```text
Web / API
    |
Spring Boot Application
    |
+--------------------+---------------------+
|                                          |
Quant Domain                              AI Gateway
|                                          |
Strategy / Backtest                       Agent Runtime
|                                          |
Portfolio / Risk                 RAG / Tools / MCP / Memory
|                                          |
+--------------------+---------------------+
                     |
          Data / Infrastructure Layer
     ClickHouse / MySQL / Redis / MQ / Python
```

核心原则：
1. Domain First
2. Agent 是智能入口，不是业务中心
3. Quant Domain 不依赖具体 LLM
4. 数据 Provider 可替换
5. Tool 是 Capability，不是 Controller
6. 所有 Agent 行为必须可追踪、可评测
7. 所有回测必须关注时间边界与数据泄露
8. 先 Modular Monolith，后按边界拆分
