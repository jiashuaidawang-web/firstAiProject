# 60天总验收标准

## 工程
- [ ] 所有核心模块可编译
- [ ] 核心 Domain 有单元测试
- [ ] 关键链路有集成测试
- [ ] Docker Compose 可启动
- [ ] 配置和 Secret 不硬编码

## 数据
- [ ] Provider 可切换
- [ ] 有数据质量检查
- [ ] 历史数据可重复获取
- [ ] 数据时间边界明确

## Quant
- [ ] Strategy 与 Backtest 解耦
- [ ] 有交易成本和滑点模型
- [ ] 有 Look-ahead Bias 检查
- [ ] 有 Out-of-Sample 验证

## AI
- [ ] 多模型 Gateway
- [ ] RAG 有引用
- [ ] Tool Schema 明确
- [ ] MCP 可独立部署
- [ ] Agent 有状态
- [ ] Agent 有 Trace
- [ ] Agent 有 Eval Dataset
- [ ] 有 Regression Eval

## 最终演示
输入一个 A 股研究问题：
1. Agent 分析任务
2. 调用市场数据
3. 查询财务数据
4. 检索金融资料
5. 根据需要运行回测
6. Risk Agent 检查
7. 输出结构化研究报告
8. 显示引用、数据时间和 Tool Trace
